# Evidencias QA V4

Esta carpeta queda deliberadamente sin resultados falsos. Adjuntar capturas/logs creados durante pruebas reales. Los archivos grandes (grabaciones, builds) preferentemente enlazarlos desde un almacenamiento externo accesible al equipo, evitando introducir archivos binarios pesados al repositorio. Cada evidencia debe referenciar un ID de prueba, commit y fecha.
